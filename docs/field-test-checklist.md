# Family Orbit 8時間実機試験

## 事前条件

- Android Internal TestingとTestFlightから親・子アプリをインストールする
- 親子各1台以上を一度限り・10分有効のQRまたはコードでペアリングする
- 自宅、学校など半径100〜5,000mの安全エリアを2件以上登録する
- 端末、OS、アプリ版、開始時刻、開始電池、通信事業者を記録する
- 位置情報と通知の説明を読み、子どもの同意を確認する

## 8時間シナリオ

| 時間帯 | 操作 | 期待結果 |
| --- | --- | --- |
| 0:00〜1:00 | 徒歩／電車で移動 | 位置が通常90秒以内、精度円と経過時間が更新される |
| 1:00〜2:30 | 建物内で停止、画面OFF | 更新間隔が延び、5分ごとの状態送信が続く |
| 2:30〜3:00 | 安全エリアへ出入り | 入退場が2分以内、同じ遷移が重複通知されない |
| 3:00〜3:30 | 機内モード | 親側に古い位置、15分後にオフラインが明示される |
| 3:30〜4:00 | 通信を復旧 | 最大24時間のキューが時系列で送られ、履歴が復元される |
| 4:00〜4:30 | 子ども側で共有停止／再開 | 停止イベントが即時反映され、停止中は位置を送らない |
| 4:30〜5:00 | 位置権限を無効／復旧 | 親子双方に権限状態が誤解なく表示される |
| 5:00〜6:00 | Android再起動／iOS強制終了 | Androidは明示状態で再開。iOSは継続を保証せずオフライン表示 |
| 6:00〜8:00 | 移動と停止を混在 | 欠測、通知遅延、端末温度、最終電池を記録する |

## 記録項目

- 位置サンプル総数、90秒を超えた件数、最長遅延、精度50m超の件数
- 安全エリア入退場ごとの検知時刻、通知時刻、重複有無
- 通信断中のサンプル数、復旧後の反映完了時刻、順序
- 8時間の電池消費率、OSのバッテリー使用内訳、異常発熱
- 親、子、Webそれぞれの空・読込・通信不能・古い位置表示
- TalkBack／VoiceOver、Dynamic Type、キーボード、44〜48px以上の操作領域

受入基準を外れた場合は、端末ログ、APIログ、時刻、端末状態をひとまとまりで記録します。緊急用途の代替として試験しないでください。
