# プライバシーと限定ベータ配布

## 必須方針

- 子ども用アプリは共有中／一時停止を常時明示し、OSの追跡通知や権限表示を隠さない
- ペアリング前に保護者の権限、利用目的、取得頻度、30日保持、停止方法を説明する
- 通知ペイロードに子どもの氏名や座標を含めず、認証後にAPIから詳細を取得する
- 家族／アカウント削除時は関連位置、端末、通知、セッション、監査データを24時間以内に完全削除する
- アクセストークンは15分、更新トークンはローテーションし、WebはHttpOnly Cookie、モバイルはKeychain／Keystoreへ保存する
- 本サービスが緊急通報ではなく、精度・到達時間・強制終了後の継続を保証しないことを表示する

## ストア提出物

- Google Play: バックグラウンド位置の主目的、アプリ内の明示説明、Foreground Service通知、デモ動画、プライバシーポリシー
- App Store: Background Locationの必要性、子ども側の可視性、強制終了時の制約、プライバシー栄養ラベル、保護者同意
- 共通: サポート窓口、削除申請手順、データ保持表、インシデント対応、正式な名称・商標・ドメインの確認

限定ベータ前に、日本法に詳しい専門家へ子どもの位置情報、保護者同意、削除・開示請求、委託先の取り扱いを確認してください。

## シークレットと配布

- `.env`、APNs `.p8`、Firebaseサービスアカウント、署名鍵をGitへ追加しない
- VPSでは権限を絞ったシークレットストアまたはrootのみ読める環境ファイルを使う
- AndroidはInternal Testing、iOSはTestFlightの許可ユーザーだけへ配布する
- 本番と検証のFCM／APNs、MongoDB、ドメインを分離する
- バックアップは毎日暗号化し7日保持、鍵はVPSとは別の安全な場所へ保存する

一般公開、多言語、チャット、SOS、到着予定共有、課金はこのMVPの対象外です。
